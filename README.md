# 🐾 Cat vs Dog Classification with SVM

##  Overview
This project develops an image classification model to distinguish between cats and dogs using **Support Vector Machines (SVM)**.

##  Steps
- Preprocessed and resized images.
- Extracted features for classification.
- Trained and evaluated **SVM** on binary classification.

## 📊 Results
- Achieved solid performance in classifying cat vs dog images.
- Showcased the strength of SVM in binary computer vision tasks.

##  Next Steps
- Improve accuracy with Convolutional Neural Networks (CNNs).
- Explore data augmentation for better generalization.
